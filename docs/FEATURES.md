# TripRank Personal Features

## 1. Map & Driving

### Map Screen
Main app screen.

Features:
- Display current location
- Display Google Maps
- Search destinations
- Select destinations from map
- Choose map light/dark mode

### Navigation Mode
Used when the user selects a destination.

Features:
- Route generation
- Turn-by-turn directions
- Voice guidance toggle
- Follow current location
- Record trip data while navigating
- Generate trip summary

### Drive Tracking Mode
Used when the user starts a drive without a destination.

Features:
- Record GPS path
- Track driving data
- Continue until user finishes the drive
- Generate trip summary

---

# 2. Trip Management

## Trip History

Users can view previous trips.

Trip list includes:
- Date
- Distance
- Vehicle used
- Basic trip summary

## Trip Details

Each trip contains:

### Basic Information
- Date and time
- Duration
- Distance
- Vehicle used

### Driving Statistics
- Average speed
- Maximum speed
- Speed data

### Route Information
- Recorded path
- Map view

### Driving Events
- Left turn count
- Right turn count
- Turn percentages
- Hard braking events
- Sudden stops
- Stops per trip
- Altitude changes

---

# 3. Vehicle Management

## Vehicle Profiles

Users can create simple vehicle profiles.

Vehicle information:
- Brand
- Model
- Year
- Type

Supported types:
- Sedan
- Hatchback
- SUV
- Pickup
- Coupe
- Van
- Other

## Vehicle Selection

The selected vehicle:
- Is remembered between sessions
- Is attached to new trips
- Filters trip history and analytics

The Cars navigation button opens vehicle selection from any relevant screen.

# 4. Analytics

## Overall Analytics

Shows general driving statistics.

Examples:
- Total distance
- Total trips
- Total driving time
- Average speed
- Driving trends

## Vehicle Analytics

Analytics can be filtered by selected vehicle.

# Product Rules

TripRank should prioritize:
- Simple interaction
- Clear information
- Minimal driving distraction
- Useful analytics

Avoid:
- Excessive statistics
- Unnecessary screens
- Features unrelated to personal driving analysis
