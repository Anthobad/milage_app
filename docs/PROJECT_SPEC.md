# TripRank Personal

## Overview

TripRank Personal is a private mobile driving companion app designed to record, analyze, and understand personal driving experiences.

The app combines map-based navigation with automatic trip tracking and driving analytics.

## Main Goal

Help users understand their driving behavior by recording trips and providing useful statistics after each drive.

## Core Concepts

### Trip
A recorded driving session containing:
- Route path
- Distance
- Duration
- Speed data
- Driving events
- Selected vehicle

### Vehicle
A simple user-created car profile used to organize trips and analytics.

Vehicle information:
- Brand
- Model
- Year
- Type

### Navigation Mode
The user selects a destination and the app provides route guidance using map services.

### Drive Tracking Mode
The user starts a drive without a destination. The app records the route and driving data until the user finishes the trip.

## Main Features

- Map-based navigation
- Automatic trip recording
- Trip history
- Trip details and analytics
- Vehicle selection and management
- Overall driving statistics

## Product Philosophy

TripRank should be:
- Simple
- Functional
- Privacy-focused
- Easy to use while driving
- Focused on useful information, not excessive data

## Out of Scope

The app is not:
- A social network
- A vehicle marketplace
- A professional fleet management system
- A replacement for dedicated navigation apps
